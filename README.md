# Phodcharaphon Sukonsakun Portfolio

Official portfolio website for Phodcharaphon Sukonsakun, Computer Engineering student at Prince of Songkla University.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Commands

```bash
pnpm install
pnpm dev
pnpm lint
pnpm build
```
